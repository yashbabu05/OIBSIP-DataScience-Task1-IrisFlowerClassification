# Iris Flower Classification 🌸

## Oasis Infobyte Data Science Internship — Task 1

## 📌 Project Overview

Iris Flower Classification is a machine learning project that predicts the species of an Iris flower based on its physical measurements. The project uses the built-in Iris dataset provided by Scikit-learn and applies classification algorithms to identify the flower species.

The project demonstrates the complete machine learning workflow, including data exploration, visualization, feature analysis, model training, performance evaluation, and model comparison.

## 🎯 Objectives

- Explore and understand the Iris dataset.
- Perform exploratory data analysis (EDA).
- Visualize relationships between flower measurements and species.
- Train and evaluate multiple classification models.
- Compare model performance and identify the best-performing classifier.

## 📊 Dataset Description

The project uses the built-in Iris dataset from `sklearn.datasets.load_iris()`. No external dataset download is required.

The dataset contains **150 samples**, three Iris species, and four numerical features.

| Feature | Description |
|---|---|
| Sepal Length | Length of the sepal in centimetres |
| Sepal Width | Width of the sepal in centimetres |
| Petal Length | Length of the petal in centimetres |
| Petal Width | Width of the petal in centimetres |

**Target classes:**
- Iris Setosa
- Iris Versicolor
- Iris Virginica

Each species has 50 samples.

## 🔍 Project Workflow

### 1. Data Loading

Loaded the Iris dataset directly from Scikit-learn and converted it into a Pandas DataFrame.

### 2. Data Understanding

Inspected the dataset using:
- `head()` to view the first five records
- `shape` to identify the number of rows and columns
- `info()` and `dtypes` to inspect data types
- `isnull().sum()` to check missing values
- `describe()` to generate descriptive statistics

The dataset contains 150 observations and four input features, with no missing values in the original measurements.

### 3. Exploratory Data Analysis (EDA)

Explored the dataset using:
- Species distribution count plot
- Pairplot to examine relationships between numerical features
- Boxplots to compare feature distributions across species
- Correlation heatmap to understand relationships between features

The visualizations indicate that petal length and petal width are particularly useful for distinguishing the Iris species.

### 4. Feature Selection

The four numerical measurements were used as input features, while the species label was used as the target variable.

All four features were retained for model training.

### 5. Data Splitting

The dataset was divided into:
- **80% training data** — 120 samples
- **20% testing data** — 30 samples

A fixed random state and stratified splitting were used to support reproducibility and preserve class proportions.

### 6. Feature Scaling

`StandardScaler` was used to standardize the input features. The scaler was fitted only on the training data and then applied to the testing data.

### 7. Model Training

Two classification algorithms were implemented:

**Logistic Regression:** A classification algorithm that estimates the probability of an observation belonging to a particular class.

**K-Nearest Neighbors (KNN):** A classification algorithm that predicts a class based on the classes of nearby training observations. The model uses five neighbors.

### 8. Model Evaluation

Both models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

These metrics help assess overall classification performance and identify which species, if any, are incorrectly classified.

### 9. Model Comparison

The accuracy scores of Logistic Regression and KNN were compared using a Pandas DataFrame and a bar chart. The model with the higher test accuracy was identified as the best-performing model for this experiment.
